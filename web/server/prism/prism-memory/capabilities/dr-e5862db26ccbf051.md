Want: per-marker 的 GC 分配字节数（哪个函数在分配多少字节），不是分配次数。当前 queryGcAllocByModule 只给 count/perFrame（次数），没有字节大小，无法判断 URP.BeforeRendering 每帧 130 次分配到底分配了多少内存、是哪种对象。
Rationale: cur 态 GC 分配 208568 次（throttle 59518 次），URP.BeforeRendering 和 Inl_OpaquePass 是大头，但只有次数没有字节，无法评估堆压力严重度，也无法定位是 command buffer / render texture / 材质属性块中的哪一种。
Axis: memory
ClosestTool: queryGcAllocByModule
