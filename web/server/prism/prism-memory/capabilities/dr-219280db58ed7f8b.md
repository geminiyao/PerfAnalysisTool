Want: GPU busy/freq counter（GPU 占用率和频率），用于从间接强信号档升级到 confirmed GPU 满载。当前只能用 wait slice 重叠法 + Render 线程变闲 + Choreographer 稳定做多信号同向，但给不出'GPU 100% 满载'硬结论。
Rationale: throttle 态单次 Gfx.WaitForPresent 17.8ms 已超 vsync，是强 GPU-bound 信号，但无 GPU counter 无法确认是 GPU 算力不足（shader 复杂/分辨率高）还是 GPU 也被热限流降频。这影响优化方向：前者优化渲染负载，后者解决散热。
