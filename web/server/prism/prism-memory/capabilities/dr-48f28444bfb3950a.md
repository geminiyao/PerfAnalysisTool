Want: per-marker 的 GC 分配字节和分配调用栈（哪个函数/Lua marker 在分配），不是整帧总量
Rationale: queryFrameCounters 只有整帧 gc_allocated_in_frame；frame 519 和 frame 483 的当帧分配都不高（8KB 级），但发生了同步 GC.Collect 70ms。多态 callTree 显示 Core.Update 的 GcAllocCount 从 4777 涨到 51365（10 倍），Core.LateUpdate 从 7907 涨到 93196（10 倍），但不知道是哪些子模块/函数在分配。要定位 GC 触发源和 10 倍分配增长的具体来源，需要到函数级/marker 级的分配明细。
Axis: memory
ClosestTool: queryFrameCounters（只有整帧 gc_allocated_in_frame，到不了函数级）；queryAggCallTreeMultiState（有 baseGcAllocCount/curGcAllocCount 但只到子树聚合级，不到单个 marker/函数级）
