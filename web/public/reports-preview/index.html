三种报告嵌入方式对比

点击下方卡片查看各方式效果 · 报告内容相同 (bk26b-perfetto-triad)
方式 A

iframe 嵌入

RunDetail 的 Tab 里用 iframe 直接嵌入 Prism HTML，保留全部原始样式和交互。

✓ 零改造成本，报告原封不动
✗ iframe 边界感，滚动嵌套
 方式 B

摘要卡 + 全屏

RunDetail 里显示评级+概览+Top3结论的摘要卡，点"全屏查看"新窗口打开完整报告。

✓ 阅读体验最佳，报告全屏展示
✗ 离开应用上下文，需切窗口
 方式 C (部分)

提取重渲染 · 摘要版

提取部分内容用应用主题重新渲染，展示风格效果。

✓ 原生体验，主题统一
✗ 违反管线契约，工作量大
 方式 C (完整版) ★

提取重渲染 · 完整报告 (§0-§7 + 优化优先级)

把 Prism 完整报告的全部 8 个章节 + 优化优先级表用 C 风格重新渲染。包含调用树进度条、判定矩阵表格、推荐建议列表、状态分布条形图。

✓ 完整报告, 阅读感最强
✗ 需为每种报告类型写对应的渲染组件
