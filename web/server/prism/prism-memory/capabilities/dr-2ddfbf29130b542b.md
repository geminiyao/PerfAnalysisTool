Topic: TryUnloadPending.TryUnload单帧内的调用次数（资源卸载数量）
Description: 已通过getSourceForSymbol确认TryUnload方法体本身逻辑简单（4行代码，CanUnload判断+DoUnload执行），但queryMarkers/scanMetricOverFrames等工具只能给出该marker在某一帧的汇总selfMs，无法得知frame80这类突发帧里TryUnload被调用了多少次（即当帧同时卸载了多少个资源对象）。
ReasonMissing: 现有的marker统计工具（scanMetricOverFrames/queryMarkers）按sampleCount可以看到调用次数的全局汇总，但没有按frame维度拆分调用次数的接口——只有耗时汇总，没有次数的frame级明细。
ImpactOnFindings: F07（资源卸载尖峰）的推理停留在"逻辑简单但可能是批量调用导致"的合理推测层面，无法用具体的调用次数数字坐实这个假设。
