§0 结论先行：三大演化结论

当前态相对基线全面退化，按涨幅强度排序的三大演化结论如下。

下钻 ① MapSignificanceMgr：Update 路径下涨 57.88 倍的最猛子节点 严重

MapSignificanceMgr 是 Update 路径下涨幅最猛的子节点——从基线 0.069ms 涨到当前 3.994ms，涨 57.88 倍，GC alloc 从 0 涨到 14043（每帧大量分配 Lua 对象）。它本身 self 只有 0.012ms（调度壳），真正成本在子节点 EntityTask（3.574ms/帧，占 89.4%）。EntityTask 下三个 ProcessTask 语义不同（添加/刷新/清理），独立拆出：ProcessTask_MapEntityAdd 1.546ms/帧 + ProcessTask_MapObjRefresh 1.198ms/帧 + ProcessTask_MapObjCleanUp 0.47ms/帧。红线判定：涨 57.88 倍 + 占 p50 9.5% → 触红线。GC 归因：每帧 alloc 14043 字节说明在 Lua 端创建大量临时表/对象（per-marker 分配源需 DR-POOL-1 补，当前工具给不了）。优化方向：复用 entity task 对象池 + ProcessTask_MapEntityAdd 分帧化（每帧只处理 N 个实体添加）。需要看 Lua 端 MapSignificanceMgr 的实现才能给具体改法。

下钻 ② CS:AOE.MeshUIManager：LateUpdate 路径新出现的大头 高
