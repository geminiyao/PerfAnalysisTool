Want: TryUnloadPending.TryUnload 单帧内的调用次数（当帧卸载了多少个资源对象）
Rationale: TryUnloadPending.TryUnload frame 80 单帧 14.59ms，但 capabilities 记录显示 TryUnload 方法体简单（4 行代码：CanUnload 判断 + DoUnload 执行），单次应该很便宜。需要知道 frame 80 调用了多少次（即当帧批量卸载了多少资源），才能确认是批量卸载导致而非单次贵。现有工具只给 marker 汇总 selfMs，给不了单帧调用次数。
Axis: cpu
ClosestTool: queryMarkers（只给 sampleCount 和 sumSelfMs，sampleCount 是采样次数不等于逻辑调用次数）
