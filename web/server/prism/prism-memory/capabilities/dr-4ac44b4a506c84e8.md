Want: GC.Collect 触发前若干帧的 per-marker/per-source 分配明细（哪个函数在持续分配导致堆累积触发同步 GC），而非整帧 gc_allocated_in_frame 总量。
Rationale: queryGcAllocByModule 给的是整个窗口的聚合分配源（URP.BeforeRendering perFrame 130 次），但无法定位具体哪一帧的哪次分配触发了 GC.Collect，也无法看 GC 触发前的累积曲线。需要逐帧 per-marker 分配字节 + 调用栈才能精准定位触发源。
Axis: memory
ClosestTool: queryGcAllocByModule（只有窗口聚合，无逐帧触发链）
