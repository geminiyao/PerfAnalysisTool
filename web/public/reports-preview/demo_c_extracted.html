§3 主线程 off-CPU 归因

throttle 态主线程 Sleeping 38.99%，其中 Gfx.WaitForPresent 占绝对主导。通过 wait slice 重叠法分离出三态的 wait 来源：base 态几乎无 wait（0.9ms），cur 态开始出现 GPU 回压（5.8ms），throttle 态 wait 爆发至 17.8ms——每次等待都超过一个 vsync 周期，说明 GPU 已完全无法在单帧内完成渲染。

三态 wait 对比: base 0.9ms → cur 5.8ms → throttle 17.8ms (×6.2 增长)

§4 降频时序

throttle 态 CPU4/CPU5 大核平均频率 1.88GHz（满频 3.0GHz 的 59%），形态为持续压制而非间歇降频。频率压制导致单帧计算变慢、GPU 指令提交延迟、swapchain 膨胀进一步加剧。

大核频率: 3.0GHz → 1.88GHz (降频 41%)

§6 GPU-bound 判定矩阵

多信号同向：①主线程 wait 占比 38.99% ②Gfx.WaitForPresent 超过 vsync ③GPU 频率未降但提交堆积 ④swapchain 膨胀。四信号同向 → 判定 GPU-bound 成立。

诚实声明: 无 GPU 计数器数据, 判定基于 CPU 侧 wait 信号间接推导
