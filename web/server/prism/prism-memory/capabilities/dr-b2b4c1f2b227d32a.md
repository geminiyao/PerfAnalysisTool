Want: GPU busy/freq counter（GPU 实际渲染耗时和频率），用于把 'GPU-bound' 从间接强信号档（wait slice 重叠法）升级到 'GPU 100% 满载' 硬结论档。
Rationale: 当前只能用主线程 Gfx.WaitForPresent 的等待时长间接推断 GPU 跟不上帧（单次 wait > vsync + coverage ≥ 80%），但无法区分是 GPU 真的 100% 满载还是 GPU 频率被压低（thermal throttle GPU 侧）。需要 GPU busy counter 才能定论。
Axis: gpu
ClosestTool: queryOffCpuAttribution（只有 CPU 侧 wait slice，无 GPU 侧 busy）
