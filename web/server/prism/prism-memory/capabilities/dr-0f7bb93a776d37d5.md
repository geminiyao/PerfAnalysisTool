Want: TryUnloadPending.TryUnload 单帧内的调用次数（当帧同时卸载了多少个资源对象）
Rationale: TryUnloadPending.TryUnload 在 frame 80 单帧 14.59ms，但源码显示 TryUnload 本身只有 4 行（CanUnload+DoUnload+state=Pooled）。queryMarkers/scanMetricOverFrames 只能给 marker 在某一帧的汇总 selfMs，无法得知 frame 80 这类突发帧里 TryUnload 被调用了多少次（即当帧同时卸载了多少个资源对象）。是 1 个大资源贵，还是 N 个小资源累加？需要调用次数才能判断。
Axis: loading
ClosestTool: queryMarkers（只能给 sumSelfMs/presentInFrames/count，count 是总调用次数不是单帧调用次数）；getFrameCallTree（看调用树但 TryUnload 是 leaf，无 children 显示调用次数）
